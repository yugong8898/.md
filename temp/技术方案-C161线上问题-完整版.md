# 技术方案：【C161】线上问题 - 油气优惠计算修复（完整版）

## 需求编号
C161

## 需求概述
司机对账和运单结算列表页勾选网货运单时，【运费差价】需要减去货主油气优惠、加上货主购买保费，使【应付】= 司机运费 + 运费差价。

---

## 字段说明（已确认）

| 业务含义 | 字段名 | 字母代号 | 备注 |
|---------|--------|----------|------|
| 应付运费（含税）- 非全流程 | `waybillToConsignorPrice` / `shipperYfAmount` | A | 后端已包含保费和油气优惠 |
| 应付运费（含税）- 全流程 | `payableFpFreight` | A | 全流程 |
| 司机运费 | `receivableTotalCost` | B | 不变 |
| 运费差价 - 非全流程（司机对账）| `serviceCharge` | C | 需要调整 |
| 运费差价 - 非全流程（运单结算）| `serviceCost` | C | 需要调整 |
| 运费差价 - 全流程 | `fpFreightDiffAmt` | C | 后端已处理 |
| 货主油气优惠 | `oilDiscountAmount` | D | 已确认 |
| 货主购买保费 | `premiumAmount` | E | 已确认 |

**需求公式**：
- **运费差价（非全流程）** = C + E - D
- **运费差价（全流程）** = C（直接用 `fpFreightDiffAmt`，后端已处理）
- **应付** = A（后端已处理 +E -D，前端不改）

## 改动原则

1. **旧代码注释保留**：不删除，注释标注 `[C161]`
2. **逻辑一致性**：三处计算逻辑完全一致
3. **三元表达式改为 if 分支**：代码更清晰易读
4. **保持原有分支结构**：
   - 全流程 B1企业：不参与统计（return total）
   - 全流程非B1企业：用 `fpFreightDiffAmt`
   - 非全流程：用 `serviceCharge/serviceCost + premiumAmount - oilDiscountAmount`
