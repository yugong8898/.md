## 改动清单

### 文件1：`driverChecking/index.vue`

**改动位置**：`selection` watch，运费差价计算（当前分支行号：第1023-1025行）

**当前代码**：
```javascript
// 运费差价（serviceCharge； 全流程对B1隐藏不参与统计）
this.selectList.totalFreightDiffAmt = this.selection.reduce((total, item) => {
  return item.fullProcessFlag === 10 && item.companyType === 1 ? total : total.plus(item.serviceCharge || 0)
}, new BigNumber(0)).toNumber()
```

**问题**：非全流程只加了 `serviceCharge`，未加 `premiumAmount`，未减 `oilDiscountAmount`

**改后代码**：
```javascript
// [C161] 运费差价 = serviceCharge + premiumAmount - oilDiscountAmount
// 旧逻辑注释保留：
// this.selectList.totalFreightDiffAmt = this.selection.reduce((total, item) => {
//   return item.fullProcessFlag === 10 && item.companyType === 1 ? total : total.plus(item.serviceCharge || 0)
// }, new BigNumber(0)).toNumber()
this.selectList.totalFreightDiffAmt = this.selection.reduce((total, item) => {
  if (item.fullProcessFlag === 10 && item.companyType === 1) return total
  if (item.fullProcessFlag === 10) return total.plus(item.fpFreightDiffAmt || 0)
  return total.plus(item.serviceCharge || 0).plus(item.premiumAmount || 0).minus(item.oilDiscountAmount || 0)
}, new BigNumber(0)).toNumber()
```
