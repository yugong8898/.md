## 一、工作经历版（直接粘贴）

**万联易达集团 · 前端开发工程师**（2026.05 – 2026.12）

负责数字货运物流平台（TMS）与企服平台两条业务线的前端研发，覆盖 PC 管理后台、H5、微信小程序、App 多端，技术栈 Vue2/Vue3 + TypeScript + Element Plus/Ant Design Vue + uni-app + Taro + qiankun 微前端。累计承接需求迭代 60 余项，按期交付率 100%，无重大生产事故。

- **主导 TMS 结算服务架构迁移**：将客户对账、日常收支、在途费用等 5 大模块 42 个接口从老链路切换至独立结算服务，覆盖 TMS PC、物流 Web、货主撮合 PC（Vue3 + qiankun 微前端 monorepo）多端；设计「接口级灰度开关 + 三层静默兜底」方案（开关异常/新服务异常/启动失败均自动回退），实现 20 个页面组件零改动、仅 5 个列表页接入，切换全程无业务中断。
- **负责资金核心链路改造**（结算信息修改回单付）：通过 BigNumber 精度控制、按触发来源区分回退策略，保证 PC/H5 双端计算行为一致，上线后零资金类事故。
- **从 0 搭建企服运营后台二级频道体系**：独立完成活动专区、智能体市场、行业资讯三大模块约 8000 行代码，采用模块目录隔离 + 组合式函数复用的可配置化架构，新增频道边际成本极低；主导该体系向 App/H5/小程序的多端适配（Taro 小程序端 + SEO 预渲染 + 后台链接字段全链路贯通）。
- **独立交付电子签章/实名认证全链路**（已上线）：设计多身份认证分流与首屏状态路由，处理请求竞态防护、签署入口守卫统一接入、CA 认证拦截全场景覆盖等复杂状态场景，覆盖雇主/服务商/供应商多角色多端。
- **独立交付企服平台多个核心模块**：服务商工作台（订单/售后/商机三动态模块骨架 + 组件拆分）、订单购买模式、指定标签服务商 T+1 结算，均按期上线且无资金类问题。
- **主导多端并行需求交付**（融合网货撮合运单）：横跨 TMS PC、物流 Web、货主移动端、货主撮合 PC 多端，期间响应 11 次需求变更仍按期上线。
- **建设 AI 辅助研发工程体系**：将 AI 工具链从单点 Skill 扩展为覆盖需求分析→代码分析→审查→缺陷排查→知识沉淀的完整流程，建立四端规则同步与知识库脚本化生成机制，沉淀 12 篇研发 SOP 供团队使用。

## 二、项目经验版（STAR 结构，挑 2–3 个放）

### 项目 1：TMS 物流结算平台（PC + H5 + uni-app 三端）

**背景**：物流财务结算系统，业务复杂度高（多角色权限、多状态运单、资金计算），后端结算服务拆分需前端配合迁移。

**职责与行动**：
- 独立完成 42 个接口的前端侧梳理，逐个标注对应服务与数据表，输出 5 份方案文档作为前后端协作基准；
- 设计接口级灰度开关 + 三层静默兜底（含静默请求、并发去重、时间节流、启动不阻断），页面层改动收敛至 5 处；
- 资金计算改造中处理浮点精度（BigNumber ±0.01 容差）、触发来源区分、移动端键盘限制等边界；
- 阅读请求库源码收敛历史重复接口定义隐患。

**成果**：迁移无业务中断、零组件级改动；资金链路双端一致、零事故；季度任务完成率 95%+。

### 项目 2：企服平台二级频道体系与核心业务模块（运营后台 Vue3 + TS + Element Plus / C 端 Taro 小程序 + H5）

**背景**：企服线新项目首个核心功能，需从 0 搭建可配置化频道体系并快速支持多端；同期承接工作台、订单结算等业务模块。

**职责与行动**：
- 从 0 搭建活动专区、智能体市场、行业资讯三模块（约 8000 行），模块化 + 可配置化架构；
- 多端适配：后台 12 处链接点位全链路贯通 H5 链接字段（DTO→Mapper→公共组件→9 个模块校验/提交），小程序端 Taro + NutUI 实现，C 端 SEO 预渲染；
- 服务商工作台：订单/售后/商机三个动态模块按「列表项/骨架/错误/空态」四状态组件拆分，mock 平滑切换真实 API；
- 订单购买模式与 T+1 结算：处理售后返工参数边界，配合测试闭环资金类缺陷；
- 建立类型检查 + 样式检查 + 41 项断言脚本的多维门禁验证。

**成果**：工作台、购买模式、T+1 结算均按期上线运行稳定；新增频道只需按模块模板扩展，边际成本极低。

### 项目 3：电子签章与实名认证（Vue3 + TS 多端）

**背景**：平台合规要求，签署前须完成企业认证/经办人实名，身份多、状态多、入口分散。

**职责与行动**：
- 多身份认证分流架构：统一状态源 + 首屏状态路由，经办人「委托书→签章」两步与其他身份单步分流；
- 请求竞态防护：短信验证码主体与流程号双重校验、状态请求卸载后续轮询治理；
- 签署守卫统一接入：两端合同页、订单列表/详情、总分包等全部签署出口收敛到守卫组合函数，CA 认证拦截全场景覆盖；
- 错误提示口径收敛：13 个文件的报错文案统一为接口层唯一来源。

**成果**：全链路按期交付并上线，多角色多端行为一致，跟测缺陷全部清零。

## 三、工作方式变革与能力沉淀（简历「个人优势」与面试素材）

### 3.1 工作方式的改变与提升

在万联易达期间，把个人研发方式从「接需求直接写代码」升级为「AI 辅助的全链路工程化研发」，并建成可复用的体系：

| 维度 | 传统方式 | 升级后的方式 |
|---|---|---|
| 研发流程 | 需求→编码→提测，过程无留痕 | 需求分析→代码分析→技术方案→编码→审查→提测→复盘七阶段编排，支持断点续跑，每阶段有可追溯产物 |
| AI 协作 | 单点问答式使用 AI | 建成覆盖需求分析、代码审查、缺陷排查、知识沉淀的 Skill 体系，多 IDE（Cursor/Qoder/CodeBuddy/Trae/Codex）规则四端同步，接入 Apifox 契约、Figma 设计稿、云效缺陷、飞书文档等 MCP 工具链 |
| 知识管理 | 文档手工维护、易过期 | 分层知识库（概览→模块→逐文件语义索引），git 驱动增量维护、脚本化生成，编码前先查库再读码 |
| 接口协作 | 口头对齐、边写边猜字段 | 契约确认四件套（字段名/类型/嵌套层级/旧参数行为）书面确认后才落码，未确认项 TODO 占位，杜绝猜测实现 |
| 影响分析 | 只改当前文件 | 横向搜索双轨制：grep 现有消费点 + 按业务语义推演潜在页面，多端逐端枚举封装函数，负结论必须附搜索式 |
| 质量验证 | 改完手工点一点 | 类型基线零新增门禁 + 断言脚本 + 分端走查留证，静态检查/自动测试/人工操作分开记录，不伪造全通过 |
| 经验沉淀 | 踩坑靠记忆 | 坑点库 + 记忆系统 + 需求复盘机制，同类错误不二犯，12 篇研发 SOP 共享团队 |

### 3.2 对未来找工作的竞争力提升

- **AI 工程化能力（稀缺复合项）**：不是「会用 AI 写代码」，而是「能为团队搭建 AI 辅助研发体系」——规则同步、Skill 资产、知识库自动化、MCP 工具链集成，这套能力可直接复制到新团队做提效落地，是多数前端简历没有的差异化亮点。
- **全链路独立交付能力**：习惯从需求拆解、技术方案、契约对齐到编码、跟测、上线、复盘完整闭环，能独立 own 模块乃至小型项目，对应高级/资深前端与前端 Owner 岗位画像。
- **复杂业务架构能力**：多身份状态分流、请求竞态防护、资金精度控制、微前端多端协同等硬场景均有落地实证，面试可展开到设计决策与边界处理层面。
- **可迁移的质量方法论**：契约先行、横向影响分析、基线门禁、证据化验证——不绑定具体技术栈，到任何团队都能快速建立质量秩序，降低协作返工。
- **跨技术栈快速迁移能力**：一年内横跨 Vue2/Vue3 + TS、uni-app 三端、Taro 小程序、qiankun 微前端多条技术线并均按期交付，证明技术栈不是瓶颈，业务理解与工程方法才是核心竞争力。
