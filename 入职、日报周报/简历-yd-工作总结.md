## 二、项目经验版（STAR 结构，挑 2–3 个放）

### 项目 1：Web3 数字藏品平台（React 18 + Next.js + Vue 3 + Koa + web3.js）

**背景**：数字藏品（NFT）发售与钱包业务，含非托管钱包 H5、NFT 市场、SSR 官网、运营后台，直接涉及链上资产与资金安全。

**职责与行动**：
- 钱包 H5 主力开发（771 次提交，仓库第一贡献者）：助记词管理、Token/NFT 转账、TokenSwap、交易明细、礼品赠送完整链路；
- 链上交互可靠性：gas 预估倍率校准避免用户多付、EIP-1559 与 Arbitrum L2 差异化 gas 策略、Uniswap 兑换集成、交易 Etherscan 可追溯、购买前钱包连接校验防资损；
- Next.js 官网 SSR/SSG + 静态预渲染上 CDN：NFT 盲盒活动按期发售，合约地址/chainId 配置化支持多链切换与活动紧急下线；
- Vue 3 + Koa 全栈后台：滑点预估、价格保护/限制、邀请码/激活码运营体系；
- 自定义 Webpack 5 懒加载优化首屏，全平台多语言（英/日/韩等）。

**成果**：多次 NFT 发售活动按期上线，链上参数切换零资损事故，钱包—市场—官网—后台全链路闭环。

### 项目 2：内容安审质检平台（React + Umi 2 + dva + Node monorepo）

**背景**：内容安全审核与机审质检平台，服务图文/视频/短视频 UGC 等多类型内容，约 20 个业务域。

**职责与行动**：
- 质检业务四期迭代：按图文/视频/召回类型分流质检任务，任务释放/禁止释放策略优化；
- 关键词库管理：组合词间距功能、库信息版本控制（类型/索引/召回 factor 不可修改约束）、历史构建集群/表追溯；
- 安审环节自见白名单提示、机器管理菜单与页面、数据统计迭代；
- 抽象通用 Excel 导入 Modal 与导入结果展示组件，多业务复用。

**成果**：质检与安审核心链路持续迭代稳定运行（684 次提交），导入类需求交付成本显著降低。

### 项目 3：「啫喱」社交产品微前端运营后台（React 18 + Umi Max 4 + qiankun）

**背景**：社交产品运营中枢，按域拆分为主应用 + 用户/资源/工具/服务/财务等 7 个 qiankun 子应用，多团队并行迭代。

**职责与行动**：
- 用户域子应用第一贡献者（180 次提交）：商城订单、钱包、商业化标签与标签库、内容管理、人群圈选、发现页精选、群组、IM 运营、辅助工具等 14 个模块；
- 参与资源域子应用（148 次提交）、主应用路由/布局、工具域与 Node 中间层建设；
- 跨子应用联调与线上缺陷闭环，支撑商城与商业化配置能力快速上线。

**成果**：微前端架构下多域并行迭代互不阻塞，用户域与资源域核心能力按期交付。
