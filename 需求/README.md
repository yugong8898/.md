## 维护规则

1. 已识别编号的原始资料放入 `进行中/<需求编号>/原始需求/`；未识别编号时先放入 `待接入/`。
2. `进行中/` 与 `已完成/` 的一级子目录只能使用需求编号；正式阶段产物使用 `阶段<序号>-<产物类型>-<需求编号>.md`。
3. 已完成时整体移动 `进行中/<需求编号>/` 至 `已完成/<需求编号>/`。
4. 副本、历史版本和压缩包只归档，不直接删除；确认无保留价值后再单独处理。
5. 目录结构或分类发生变化时，同步更新本索引。
