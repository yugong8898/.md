# REQ\-170 订单模式直采支持变成反采

# 需求

[REQ\-170 原直采模式支持雇主购买前选择购买模式\-PRD](https://wanlianyida.feishu.cn/wiki/UVaDwYXQViKS3AkhSgxcnRp2nMd)



# 技术方案

确认订单页，接口新增返回 canChangeOrderType : true/false, 为true时，展示选择框。用户选中后，在创建订单接口中orderType传2
