## 一、现状分析

### 1.1 涉及文件清单

| 文件路径 | 当前职责 | 前缀引用方式 |
|---------|---------|-------------|
| `src/config/project-config.ts` | 接口前缀配置 | 定义 `apiPrefixConfig.lmtUser = '/lmt-user'` |
| `src/service/index.ts` | http 封装（`@wlydfe/service`） | 默认 urlPrefix，支持 `urlGateway` 参数 |
| `src/api/reconciliation/index.ts` | 客户汇总/对账单/对账明细 | `const LMT_USER = apiPrefixConfig.lmtUser` → 模板字符串 |
| `src/api/financial-management/daily-income.ts` | 日常收入 | 硬编码 `/lmt-user/income/*` |
| `src/api/financial-management/daily-expense.ts` | 日常支出 | 硬编码 `/lmt-user/expenditure/*` |
| `src/api/inTransit/index.ts` | 在途费用（主） | `GATEWAY = { urlGateway: '/gateway/lmt-user' }` 传参 |
| `src/api/waybill/index.ts` | 在途费用（重复定义） | 硬编码 `/lmt-user/route-cost/*` |

### 1.2 http 调用机制

```
http.post({ url, data }, options?)
```

- `options` 为 `RequestOptions`，支持 `urlGateway` 属性指定网关前缀
- 不传 `urlGateway` 时用默认 urlPrefix
- `apiPrefixConfig.lmtUser = '/lmt-user'`（不带 `/gateway`）
- `inTransit` 中 `urlGateway: '/gateway/lmt-user'`（带 `/gateway`）

### 1.3 前缀引用方式差异（改造核心难点）

| 方式 | 文件 | URL 示例 | options 传参 |
|------|------|---------|-------------|
| A 变量拼接 | `reconciliation/index.ts` | `` `${LMT_USER}/lscWaybill/page` `` | 不传 |
| B 硬编码 | `daily-income.ts` | `/lmt-user/income/page` | 不传 |
| C 硬编码 | `daily-expense.ts` | `/lmt-user/expenditure/page` | 不传 |
| D GATEWAY 传参 | `inTransit/index.ts` | `/route-cost-query/cost-apply-list` | `{ urlGateway: '/gateway/lmt-user' }` |
| E 硬编码 | `waybill/index.ts` | `/lmt-user/route-cost/cost-audit` | 不传 |

> 方式 A/B/C/E 的 URL 中带 `/lmt-user` 前缀；方式 D 的 URL 不带前缀，通过 `urlGateway` 参数指定。两种方式最终请求路径一致，但拼装方式不同。

### 1.4 模块关系

```
页面组件 → import API 函数 → http.post({ url, data }) → @wlydfe/service → 网关 → 后端服务
                                    ↑
                              url 前缀（当前固定 /lmt-user，需改为可切换）
```

### 2.3 关键逻辑设计

#### 逻辑1：迁移开关服务（`tms-settlement-switch.ts`）

- 触发条件：模块级开关查询（应用初始化、路由进入财务/在途模块时）
- 处理步骤：
  1. 调用开关接口查询各模块开关状态（接口路径待后端确认）
  2. 缓存开关结果到内存（模块维度，如 `reconciliation`、`daily-income`、`daily-expense`、`in-transit`）
  3. 开关接口异常时，默认返回 `false`（走老链路）
- 异常处理：开关查询失败 → 降级走老接口，记录日志

伪代码：
```typescript
// 开关缓存
const switchCache: Record<string, boolean> = {}

// 查询开关（模块维度）
async function getTmsSettlementSwitch(module: string): Promise<boolean> {
  if (module in switchCache) return switchCache[module]
  try {
    const res = await http.post({ url: '/lmt-user/tms-migration-switch/query', data: { module } })
    switchCache[module] = res?.model === true
  } catch {
    // TODO: wxj 开关接口路径待后端确认，异常时默认走老链路
    switchCache[module] = false
  }
  return switchCache[module]
}
```

#### 逻辑2：前缀解析器（`tms-settlement-prefix.ts`）

- 触发条件：每个 API 函数调用时
- 处理步骤：
  1. 接收模块名参数
  2. 同步读取开关缓存（已预加载），返回前缀字符串
  3. 开关关闭 → 返回 `/lmt-user`（老前缀）
  4. 开关开启 → 返回 `/tms-settlement`（新前缀）
- 异常处理：缓存未命中时默认返回老前缀

伪代码：
```typescript
import { apiPrefixConfig } from '@/config/project-config'

// 同步获取前缀（依赖开关已预加载到缓存）
function getSettlementPrefix(module: string): string {
  const enabled = switchCache[module] ?? false
  return enabled ? apiPrefixConfig.tmsSettlement : apiPrefixConfig.lmtUser
}

// 获取 GATEWAY 选项（兼容 inTransit 的传参方式）
function getSettlementGateway(module: string): { urlGateway: string } {
  const enabled = switchCache[module] ?? false
  const prefix = enabled ? '/gateway/tms-settlement' : '/gateway/lmt-user'
  return { urlGateway: prefix }
}
```

### 3.2 开关维度设计

需求文档说"接口纬度"，但 app-base 中同一模块的接口分散在多个文件。**建议按模块维度管理开关**，理由：

| 维度 | 开关数量 | 管理成本 | 灰度粒度 |
|------|---------|---------|---------|
| 接口维度 | ~50 个 | 高（每个接口单独配置） | 最细 |
| 模块维度 | 4 个 | 低（reconciliation/daily-income/daily-expense/in-transit） | 适中 |

**推荐模块维度**，开关配置：

| 模块 key | 涉及 API 文件 | 说明 |
|----------|-------------|------|
| `reconciliation` | `reconciliation/index.ts` | 客户汇总+对账单+对账明细 |
| `daily-income` | `daily-income.ts` | 日常收入 |
| `daily-expense` | `daily-expense.ts` | 日常支出 |
| `in-transit` | `inTransit/index.ts` + `waybill/index.ts` | 在途费用 |

### 3.4 兼容性影响

| 影响点 | 影响范围 | 风险等级 | 应对措施 |
|--------|---------|---------|---------|
| 开关接口未上线 | 全部模块 | 高 | 开关查询异常默认走老链路（降级） |
| 新服务不可用 | 已开启开关的模块 | 高 | 运维关闭开关，前端缓存失效后自动切回 |
| 在途费用重复定义收敛 | `waybill/index.ts` 调用方 | 中 | 用 re-export 保持函数签名不变，调用方无感 |
| 前缀拼装方式不同 | `inTransit` 模块 | 中 | 提供 `getSettlementGateway` 函数统一处理 |
| 开关缓存与实际不一致 | 开关切换后短时窗口 | 低 | 开关切换时清缓存 + 页面刷新 |
