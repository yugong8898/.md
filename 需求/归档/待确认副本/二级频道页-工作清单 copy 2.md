### 1.2 统一协作规则（已确认）

1. 每个模块固定交付**五件套**：`index.vue`、`types.ts`、`validate.ts`、`submit.ts`、`readonly.vue`；
2. 模块校验只写在自己的 `validate.ts`；
3. 模块提交结构只写在自己的 `submit.ts`；
4. 详情页只消费各模块 `readonly.vue`；
5. 公共 API、公共状态、路由权限由梁树强统一维护；
6. 大表单外壳、模块注册、总校验、总提交由张立统一维护。

### 1.3 模块交付物说明

| 文件 | 职责 |
|---|---|
| `index.vue` | 表单编辑态（模块开关、前台展示名称、子项增删改、查看更多等） |
| `types.ts` | 模块数据结构定义（字段名占位，联调时集中替换） |
| `validate.ts` | 导出 `validateModule(formData): Promise<{ valid, message? }>`，提交审核时由总校验链调用 |
| `submit.ts` | 导出 `buildModulePayload(formData): { moduleKey, data }`，由总提交汇总 |

## 3. 二、现状代码盘点

实读代码确认（2026年09月）：

- **三模块均为占位**：`index.vue` 为 `el-empty`（7 行）；`validate.ts` 恒返回 `{ valid: true }`；`submit.ts` 用 `createEmptyModulePayload` 透传；`types.ts` 为空结构。
- **注册机制已就绪**：`form/module-registry.ts` 已登记三模块 `component / validate / buildPayload`；`form/index.vue` 提交时按注册顺序逐模块校验，失败自动切换左侧导航定位并 `ElMessage.warning`。**沿用该机制，不绕开。**
- **接口层全 mock**：`src/api/secondary-channel/index.ts` fetch `mock/data.json` + 模块级内存缓存（刷新丢失）。先按约定数据结构开发，真实接口切换只改封装层。
- **枚举已落地**：`constants.ts` 已定义 11 类目、线上/变更/审核三组状态。
- **只读消费方未建**：三个详情页由梁树强开发，统一消费 `readonly.vue`。

## 4. 三、通用业务规则

### 4.1 三模块同构配置项

| 配置项 | 规则 |
|---|---|
| 启用/禁用开关 | 控制模块前台展示；**禁用不删除已配置数据**，重新启用可继续使用 |
| 前台展示名称 | 模块启用时**必填**；用于前台模块标题 |
| 查看更多开关 | 开启时可填跳转链接；关闭后前台不展示入口，**已填链接保留** |
| 跳转链接 | 标准网址格式校验；前台统一新窗口打开；禁止危险脚本链接 |

### 4.2 图片规则（三模块统一）

- 仅支持 PNG / JPG / JPEG，单张 ≤ 20MB；
- 上传成功后展示图片预览；
- 未配置或加载失败时前台展示缺省态（后台编辑态展示占位）。

### 4.3 校验与提交机制

- **保存草稿不触发校验；提交审核才校验**（总校验链由张立维护，逐模块调用 `validate.ts`）。
- 各模块数据挂在 `formData.modules[moduleKey]` 下，`moduleKey` 与注册表一致：`agent-market` / `activity-zone` / `industry-news`。
- **数据结构先行**：先定 `types.ts` 再开发，组件内不散落真实接口字段硬编码；联调时只改封装层映射。

### 4.4 `readonly.vue` 契约

- 与 `index.vue` 平级，消费同一份 `types.ts`；
- 图片可预览、链接可点击并新窗口打开；
- 入参形态（收模块 `data` or 从 `formData` 取）开发前与梁树强/张立对齐一次（待确认 #12）。

## 12. 十一、开发顺序建议

1. **契约先行**：与梁树强定 `readonly.vue` 入参契约（#12）；与梁树强/后端定检索接口归属（#13）；找产品锁定 #1 #2 #3；
2. **公共件**：模块表头、查看更多、图片上传封装、链接校验工具；
3. **行业资讯**：结构最简单，打通「表单 → 校验 → payload → readonly」全链路；
4. **智能体市场**：复用资讯模式，增加封面图选填与启用状态；
5. **活动专区**：复杂度最高（双选择弹窗 + 开关联动 + 拖拽），放最后；#1 #2 有结论后收敛校验口径；
6. **联调**：接口契约确认后统一替换封装层，走第 11 节回归。

## 13. 十二、风险点
