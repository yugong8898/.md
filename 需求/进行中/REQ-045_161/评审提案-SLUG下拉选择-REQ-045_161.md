# 二级频道访问地址配置优化提案

建议将运营后台的 SLUG 手动输入改为**从已登记的路径中选择**。运营按业务名称选地址，提交前能看到完整链接。品牌专区和活动需要新路径时，可按需登记。

## 现状

工商财税频道拟接入新域名 `cs.wdsheng.com`。如果继续沿用 `/gscs`，对应访问地址为 `https://cs.wdsheng.com/gscs`。其中 `gscs` 对应后台发布配置的 SLUG，前台会用这个值向接口查询频道内容。

后台当前允许手动录入符合格式的 SLUG，校验范围是小写字母、数字、减号及长度。例如 `gscs` 写成 `gcss`，两者均可通过格式校验。错误值可能导致发布地址与业务投放地址不一致。已投放页面如果换址，还会涉及搜索收录、广告素材和历史分享链接。

## 方案

| 场景 | 操作与规则 |
|---|---|
| 新建频道 | 发布配置中的「访问地址」下拉支持按业务名称和路径搜索。选项展示「工商财税 · /gscs」，选中后展示完整 URL。继续使用现有 SLUG 字段提交。 |
| 地址已分配 | 显示占用状态，禁止分配给其他页面。服务端保存时再次校验，防止多人同时选中同一地址。 |
| 日常更新内容 | 回显并保留历史 SLUG，包括尚未登记进清单的值。更换内容、Banner 或模块顺序时，运营可以继续沿用当前地址。 |
| 新品牌或活动 | 负责人登记业务名称、域名、路径和用途，登记完成即可在后台选择。 |
| 已上线频道换址 | 审核时展示原地址和新地址。上线前确认旧链接继续服务或跳转，并明确投放入口的更新责任。 |

## 为什么本期值得做

- **减少发布错误。** 运营认得「工商财税」，未必记得 `gscs`。下拉直接展示业务名称和完整链接，可以在审核前发现选错页面。
- **保障投放地址稳定。** 内容变更可以直接沿用已有地址。换址时集中核对新旧链接，减少发布完成后再处理历史物料。
- **保留活动灵活性。** 路径仍可按业务需求新增。登记时一次确认用途、可用性和归属，之后配置、审核和投放都使用同一条记录。
- **便于分步落地。** 首批只需准备本期地址清单，接入下拉与历史回显。业务可先由指定负责人维护清单，地址规模扩大后再评估维护入口。

## 评审需拍板

1. **工商财税发布地址。** 确认 `https://cs.wdsheng.com/gscs` 是否为正式地址，原 `https://channel.wdsheng.com/gscs` 继续访问还是跳转。
2. **地址登记责任。** 产品或业务确认首批清单及维护负责人，研发按清单接入选择与校验。
3. **地址唯一规则。** 当前频道前台查询会传 SLUG。若两个域名的同名路径需要展示不同页面，先由后端确认是否支持按域名与路径共同匹配，再确定下拉的占用规则。

建议评审通过后，按「首批地址登记 → 后台下拉与历史回显 → 验证新旧地址」推进。
