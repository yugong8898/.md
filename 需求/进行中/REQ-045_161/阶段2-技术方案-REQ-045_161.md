## 核心架构决策

### D1 模块双轨制：存量单例不动，新增模块走实例层（最小改动）

- 存量 12 模块（含需求留言）的注册表、`formData.modules[key]` 数据结构、五件套、双向映射**全部保持不变**，旧类目频道回显与提交零回归风险。
- 新增 Banner、新增智能体市场以**实例数组**承载：`formData.instances: ModuleInstance[]`，每项含 `instanceId`（前端 local_id，参考 agent-market 现有生成规则）、`moduleType`（banner / agent-market）、`backendName`（后台名称 ≤30 字）、`enabled`（新增默认 false）、`data`（模块业务数据）。
- 实例数据槽位键 `instance:${instanceId}`，仍存于 `formData.modules`，复用现有 `getModuleData/setModuleData` 通道，不新建并行状态体系。
- 拒绝的替代方案：全模块实例化重构——改动面覆盖全部存量模块与旧数据迁移，违背最小改动原则。

### D2 导航顺序：统一 displayOrder 列表，server 契约为最终依据

- `formData.displayOrder` 维护「页面展示模块」统一顺序（存量模块 key + 实例 instanceId 混排）；底部配置（footer）、发布配置（publish）固定不参与。
- 回显：优先消费 server 返回的顺序结构（契约 C3）；未下发时按注册表顺序 + 实例追加末尾兜底。
- 提交：顺序随 config 提交（契约 C3）；拖拽/上移/下移只改 displayOrder，首尾禁用对应方向。
- 旧数据无顺序字段时按注册表顺序回显，保存后写入顺序——兼容抓手沿用 `build-api-config.ts` 基线复制机制。

### D3 智能体市场实例复用现有组件，数据键参数化

- `agent-market/index.vue` 现硬编码读写 `'agent-market'` 键；改造为接受可选 `dataKey` prop（缺省 `'agent-market'`，存量行为不变），实例外壳传入 `instance:${id}`。
- 卡片级配置、数量上限、拖拽（useDragSort）逻辑原样复用；实例级启用开关与后台名称由实例外壳承载。

### D4 新 Banner 独立模块目录，不改存量 bottom-banner

- 新建 `form/modules/instance-banner/` 五件套；图片宽 1200px、高度不限、不固定裁切（区别于 bottom-banner 的 1200×150~300 固定裁切，旧常量与裁切逻辑不动）。
- 跳转沿用底部 Banner 的无跳转/有跳转模式；格式 PNG/JPG/JPEG ≤20MB。

### D5 TDK 静态预置：追加条目，不改机制

- 向 `wds-web-channel/build/seo-tdk.mjs` 的 `SEO_STATIC_PAGES` 追加条目（内容待产品 Q-01），构建预渲染与运行时自动共用。
- 独立页匹配键待契约 C6：现机制按 `categoryId` query 命中，独立页无类目，需扩展匹配维度（预计按 slug 或新 query 键）；未确认前只加 TODO: wxj 占位，不落地推测实现。
- 存量 categoryId=4/9 条目与命中逻辑注释保留不删除；cs 域名接入由运维负责，前端仅回归。

## 关键逻辑设计

### L1 创建流程（R-001）

1. 列表页「配置二级频道」→ 弹 PageTypeDialog（类目频道页/独立页面）。
2. 类目频道页 → 进入现有 select-category 类目卡片链路（不变）。
3. 独立页面 → 弹窗下方展开名称输入：空值提示「请输入页面名称」、30 字超出不能输入、切换类型保留输入、关闭重开清空。
4. 下一步 → 调 init（契约 C4，独立页入参无 categoryId）；重名由 server 返回，前端 toast「当前名称已存在，请重新编辑」；成功进入表单。
5. 建档时点、退出是否留记录由 server 行为决定，前端不做本地预判。

### L2 名称编辑与列表（R-002）

- 配置页顶部：类型标签 + 独立页名称编辑态（确认/取消；取消无效；确认查重，重名 toast 同 L1；30 字限制），确认后同步顶部与列表名称显示。
- 列表：名称列取值类目频道=类目名称、独立页=自定义名称（契约 C1）；类型筛选「全部页面类型/类目频道页/独立页面」；搜索覆盖两类。

### L3 实例添加/计数/删除（R-004/R-005）

- 添加弹窗：Banner/智能体市场下拉；按类型计数（禁用仍计数），单类满 5 禁选、两类均满禁用添加按钮；顶部轮播、底部 Banner、已有智能体市场不计入。
- 新增成功：实例默认关闭、追加 displayOrder 末尾、自动选中；默认名「Banner N」「智能体市场 N」分类编号（编号取该类型当前最大序号+1，删除不回填）。
- 后台名称编辑：所有模块（含存量）标题后「编辑」入口，30 字，确认同步导航；前台展示名称走现有 displayTitle 不受影响。
- 删除：仅新增实例可删，二次确认（标题「删除模块」，正文按 PRD 文案含模块名）；确认仅改当前草稿，需保存/提交审核生效；存量模块无删除入口。
- 排序：拖拽（useDragSort）+ 上移/下移按钮，首尾禁用对应方向；footer 固定底部；审核中（isAuditing）全部实例操作禁用。

### L4 独立页模块形态（R-003）

- pageType 经 formContext 下发；category-list 独立页隐藏展示形式选择仅留图片配置；recommended-services 显示启停开关；latest-services 独立页从可见注册表过滤。
- 类目频道页行为完全不变（条件分支以 pageType 为准，不做运行时猜测）。

### L5 前台数据驱动渲染（R-004/R-005 前台侧）

- server 页面接口返回启用模块数组（含类型、顺序、实例数据，契约 C5）；模板按数组顺序映射组件渲染。
- 保留既有行为：顶部轮播压底重叠（-124px）、快捷入口派生判断、断网 EmptyState、骨架屏、空配置跳主站、localStorage categoryId 同步。
- 独立页无类目数据时相关区块自然不渲染（数据驱动，无需特判）。

### L6 TDK 预置（R-008）

- 产品提供清单（Q-01）→ 追加 SEO_STATIC_PAGES 条目 → 构建生成 dist/seo/*.html → 运行时命中覆盖接口 seo。
- 独立页匹配键与 nginx rewrite 待 C6 与运维确认；确认前条目结构预留、匹配逻辑 TODO: wxj 占位。

## 开发顺序建议

1. **类型与契约占位层**：api-types/list.types/module-types 扩展 + constants（C1/C3/C4 TODO 占位）——后续全部依赖。
2. **创建流程与列表**（R-001/R-002）：PageTypeDialog、select-category 入口、list 列/筛选/mapper——独立可验证。
3. **表单壳实例层**（R-004/R-005 骨架）：formData 扩展、双轨导航、displayOrder、添加/删除/排序/名称编辑组件——核心结构，依赖 1。
4. **新模块与存量适配**（R-003/R-006）：instance-banner 五件套、agent-market dataKey、category-list/recommended-services/latest-services 独立页形态——依赖 3。
5. **映射与详情回显**：build-api-config/config-mapper/detail 映射 + readonly 实例卡片——依赖 3/4，旧数据兼容在此闭环。
6. **前台数据驱动渲染**（wds-web-channel）：依赖 C5 占位结构，可与 5 并行。
7. **TDK 预置与收尾**：seo-tdk 条目（待产品内容）、匹配键占位、主站入口回归——最后执行，内容到位即填入。

批次划分：1+2 一批、3 一批、4+5 一批（同模块强依赖）、6 一批、7 一批；每批出口跑项目 lint/类型检查门禁。
