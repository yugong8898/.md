## 通用约定

### 鉴权
- 所有接口均须登录态，校验服务商身份及权限
- 商机、订单、售后仅认证通过时展示

### 请求方式
- 统一 `GET`

### 响应结构
```jsonc
{
  "succeed": true,       // 成功 true / 失败 false
  "code": "",            // 失败时错误码
  "message": "",         // 失败时错误信息
  "model": { ... }       // 成功时业务数据，失败时 null
}
```

### 分页约定
- `page`：`int32`，默认 `1`，最小 `1`
- `pageSize`：`int32`，默认 `6`，范围 `1～6`
- 无匹配时 `total=0, list=[]`
- 超出末页时 `list=[]`，`total` 仍为全量数
- 消息接口不分页

### 时间格式
- 北京时间：`yyyy-MM-dd HH:mm:ss`
- 相对时间文案：由 `helper.DisplayTime` 生成（刚刚、3分钟前、日期等）

### ID 类型
- 所有 ID 字段均为字符串
- 计数为 `int64`
- 金额字段为字符串（精确两位小数，如 `"500.00"`），不使用浮点数

## 一、售后动态

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `providerId` | `string` | 是 | 服务商 ID，校验归属后传 `provider_id` |
| `page` | `int32` | 否 | 目标页码，默认 `1` |
| `pageSize` | `int32` | 否 | 每页条数，默认 `6`，范围 `1～6` |

### 内部条件（非 HTTP 入参）

| 条件 | gRPC 映射 | 说明 |
|------|----------|------|
| 待办范围 | `after_sale_status=101` | 待处理 + 待提交交付物（组合值，拟定中） |
| 保留平台介入 | `show_normal_status_transferred_to=true` | - |
| 客服范围 | `provider_account_id` | 暂不传，过滤规则待确认 |

### 响应字段（`model`）

| 字段 | 类型 | 中文含义 | 说明 |
|------|------|---------|------|
| `total` | `int64` | 售后待办总数 | 同一筛选条件的分页前全量数量 |
| `list[]` | `array` | 售后动态列表 | 当前页最多 `pageSize` 条，页面默认展示 2 条 |
| `list[].afterSaleId` | `string` | 售后编号 | 原 ID 转字符串 |
| `list[].orderId` | `string` | 订单 ID | 原 ID 转字符串 |
| `list[].goodsName` | `string` | 服务名称 | 售后快照名称原值 |
| `list[].employerName` | `string` | 雇主名称 | 售后单中的雇主名称快照原值 |
| `list[].afterSaleType` | `int32` | 售后类型 | `0` 未指定、`1` 仅退款、`2` 仅返工、`3` 退款+返工 |
| `list[].afterSaleTypeCode` | `int32` | 售后类型编码 | 同 `afterSaleType` |
| `list[].applyTime` | `string` | 发起时间 | 北京时间 `yyyy-MM-dd HH:mm:ss`，卡片"更新于"用此字段 |
| `list[].afterSaleStatus` | `int32` | 售后展示状态 | 服务端派生的真实状态 |
| `list[].afterSaleStatusText` | `string` | 售后状态文案 | - |
| `list[].exceptionAfterSaleStatus` | `int32` | 平台介入子状态 | 保留 `int32` |
| `list[].exceptionAfterSaleStatusText` | `string` | 平台介入状态文案 | - |

### 处理规则
- 按 `apply_time DESC` 排序
- `101` 只作查询组合值，卡片使用真实状态
- 待交付包含修改中、验收驳回及平台介入下对应场景

## 二、订单动态

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `providerId` | `string` | 是 | 服务商 ID，校验归属后传正 `int64` 的 `provider_id` |
| `page` | `int32` | 否 | 目标页码（现有契约无页定位字段，待下游补齐） |
| `pageSize` | `int32` | 否 | 每页条数，与现有 `limit` 的 `1～6` 范围一致 |

### 内部条件（非 HTTP 入参）

| 条件 | gRPC 映射 | 说明 |
|------|----------|------|
| 客服范围 | `provider_account_id` | 可信登录身份解析：主账号传 `0`，客服传实际账号 ID |

### 响应字段（`model`）

| 字段 | 类型 | 中文含义 | 说明 |
|------|------|---------|------|
| `pendingBondCount` | `int64` | 待缴保证金数 | 分页前完整统计，沿用 REQ-129 |
| `pendingDeliveryCount` | `int64` | 待交付数 | 分页前完整统计，沿用 REQ-129 |
| `total` | `int64` | 订单待办总数 | 两类按订单 ID 去重后的全量并集，不受分页限制 |
| `list[]` | `array` | 订单动态列表 | 目标为当前页最多 `pageSize` 个不同订单，每订单保留最新有效待办 |
| `list[].orderId` | `string` | 订单 ID | ID 转字符串 |
| `list[].orderNo` | `string` | 订单编号 | 当前同订单 ID 字符串 |
| `list[].goodsName` | `string` | 服务名称 | 原值 |
| `list[].employerName` | `string` | 雇主名称 | 原值 |
| `list[].todoType` | `string` | 待办类型 | `PENDING_BOND_PAYMENT`（待缴履约保证金）/ `PENDING_DELIVERY`（待提交交付物） |
| `list[].todoText` | `string` | 待办标签 | "待缴履约保证金" / "待提交交付物" |
| `list[].rejected` | `boolean` | 是否驳回 | 是否驳回等需重新提交 |
| `list[].bondAmount` | `string` | 保证金金额 | 分字符串精确转元、固定两位，如 `"50000"` → `"500.00"` |
| `list[].orderAmount` | `string` | 订单实付金额 | 同上 |
| `list[].orderCreateTime` | `string` | 订单创建时间 | RFC3339 转北京时间 `yyyy-MM-dd HH:mm:ss`，保证金卡用此字段 |
| `list[].actionChangedAt` | `string` | 当前待办生效时间 | 同上；历史未知保留空串，不用其他时间填充，交付卡用此字段 |
| `list[].actionTarget.source` | `string` | 待办来源 | `ORDER` / `ORDER_STAGE` / `AFTER_SALE_REWORK` |
| `list[].actionTarget.action` | `string` | 待办动作 | `PAY_BOND` / `SUBMIT_DELIVERY` |
| `list[].actionTarget.stageId` | `string` | 阶段 ID | 转字符串，无关联为 `"0"` |
| `list[].actionTarget.afterSaleId` | `string` | 售后单 ID | 转字符串，无关联为 `"0"` |

### 处理规则
- 主账号/客服身份必须先验证，账号解析失败不能回退为主账号 `0`
- 下游先按订单确定最新有效待办、去重及按 `action_changed_at DESC, order_id DESC` 排序，再分页
- 两分类计数及 `total` 保持全量，不以子项之和或列表长度替代
- 订单 RPC 补齐分页契约前不能翻页，BFF 不截取现有最多 6 条模拟后续页

### 进行中订单总数
- 继续调用原 `GET /v1/provider/statistics`
- 取完整路径 `model.list[type=ongoingOpportunities].num`
- 源于 `ProviderStatistics.ongoingOpportunities`，原值为字符串
- 保持服务商全量统计，不按客服过滤
- 不在新订单响应中增加统计字段

## 三、消息未读

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `providerId` | `string` | 是 | 服务商 ID，校验归属后作为 `external_id`，保留字符串 |

### 内部条件（非 HTTP 入参）

| 条件 | gRPC 映射 | 说明 |
|------|----------|------|
| 消息来源 | `external_type="esp"` | - |
| 分类范围 | `tab=""` | 一次取全部分类 |

### 响应字段（`model`）

| 字段 | 类型 | 中文含义 | 说明 |
|------|------|---------|------|
| `total` | `int64` | 总未读数 | 当前服务商全部分类未读计数 |
| `byTab.service` | `int64` | 服务通知未读数 | 按分类取值，缺项补 `0` |
| `byTab.transaction` | `int64` | 交易消息未读数 | 同上 |
| `byTab.aftersale` | `int64` | 售后消息未读数 | 同上 |
| `byTab.system` | `int64` | 系统通知未读数 | 同上 |

### 处理规则
- 使用未读计数 RPC，不使用消息列表接口的消息总条数
- 某分类未读数为 `0` 时禁用对应"去处理"按钮

## 四、需求推荐

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `providerId` | `string` | 是 | 服务商 ID，校验归属后传类目 RPC 的 `provider_id` |
| `page` | `int32` | 否 | 目标页码，保留 `int32` |
| `pageSize` | `int32` | 否 | 每页条数，保留 `int32` |

### 内部条件（非 HTTP 入参）

| 条件 | gRPC 映射 | 说明 |
|------|----------|------|
| 匹配类目 | `pairs[].category_id/category_level` → 检索 `categories[]` | 按现有逻辑展开，类目 ID 转字符串 |
| 关键词、地区、预算、周期 | 均不传 | 可选参数不补 `0` |

### 响应字段（`model`）

| 字段 | 类型 | 中文含义 | 说明 |
|------|------|---------|------|
| `total` | `int64` | 匹配需求总数 | 同一条件在分页前的 ES 全量命中数 |
| `list[]` | `array` | 推荐需求列表 | 当前页最多 `pageSize` 条 |
| `list[].id` | `string` | 需求 ID | ID 转字符串 |
| `list[].title` | `string` | 需求标题 | 原值 |
| `list[].categoryId` | `string` | 类目 ID | 原值，ID 为字符串 |
| `list[].categoryLevel` | `int32` | 类目层级 | 原值 |
| `list[].categoryPath` | `string[]` | 完整类目名称路径 | 按 `categoryId` 补齐，复用类目缓存，根到叶排列；无路径时为空数组 |
| `list[].categoryName` | `string` | 末级类目名称 | `categoryPath` 最后一项，如"数据标注与清洗"；无路径时为空字符串 |
| `list[].budgetMin` | `string` | 预算下限 | 金额已由 gRPC 转为元，不再除以 `100` |
| `list[].budgetMax` | `string` | 预算上限 | 同上 |
| `list[].budgetUnit` | `string` | 预算单位 | 原字符串 |
| `list[].deliveryCycleMin` | `string` | 周期下限 | 保留 `null` |
| `list[].deliveryCycleMax` | `string` | 周期上限 | 保留 `null` |
| `list[].deliveryCycleUnit` | `string` | 周期单位 | 原字符串，如自然日 |
| `list[].realCreateTime` | `string` | 发布时间 | Unix 秒转北京时间 `yyyy-MM-dd HH:mm:ss` |
| `list[].createTime` | `string` | 发布时间文案 | 复用 `helper.DisplayTime`，如刚刚、3分钟前、日期 |
| `list[].matchLabel` | `string` | 推荐标签 | BFF 固定文案"为你推荐" |

### 处理规则
- 没有已上架服务类目时直接返回 `total=0/list=[]`，不以空类目查询全大厅
- 仅按类目匹配，按 `create_time DESC, id DESC` 排序
- 双时间（`realCreateTime` / `createTime`）来自同一时间戳
