## 1. 需求概述

服务商工作台首页改版，核心变更：

1. **新增三个业务动态模块**：重要商机推荐、订单动态、售后动态——本质是已有列表页某一状态子集的工作台快捷入口（前 N 条 + 计数），不是新业务
2. **进行中订单指标卡增强**：内嵌「待缴纳保证金 / 待提交交付物」两个履约状态计数及跳转入口
3. **行动中心 → 消息中心**：移至右侧列，改名，功能不变；「去处理」无消息时真正禁用
4. **发布服务独立强化**：从行动中心抽出，UI 突出
5. **未认证/已认证差异化展示**：未认证展示兜底流程图 + 认证引导；已认证展示「了解接单规则」弹图

本期不做（范围外）：运营后台（es-ops-platform）、雇主端、供应商端、推荐算法优化、消息推送能力建设。

## 5. 数据来源与现状代码事实

> 以下均为 2026-10-20 实读 `ai-platform/es-web` 源码所得，作为阶段 1 基线。

### 5.1 PRD 明确的取值口径

| 模块 | 取值规则 |
|---|---|
| 订单动态 - 待缴纳保证金 | 订单状态为「待缴纳保证金」 |
| 订单动态 - 待提交交付物 | 订单状态维度：**订单状态 = 履约中** 且 **阶段状态 = 履约中 / 验收驳回**；售后单状态维度：售后状态 = 修改中 / 验收驳回，或 平台介入-修改中 / 验收驳回 |
| 售后动态 | 售后状态 = 待处理；类型含全部三类（含平台介入下的三类） |

## 12. 开发顺序建议

采用「先骨架、后契约」两段式，避免被 Q1–Q5 阻塞：

**第一批（与接口无关，可立即开始）**
1. 三个模块容器组件（标题栏 / 角标 / 查看更多 / 刷新）

9. 详情跳转 + 锚点定位
