
## 5. 接口无关中间层设计

为规避 Q1（接口形态未定）阻塞，采用**接口无关中间层**：

### 5.1 Composable 抽象

```typescript
// composables/useDynamicModule.ts
export function useDynamicModule<T>(
  fetchFn: () => Promise<{ list: T[]; total: number }>,
  options: { pollingInterval?: number } = {},
) {
  const list = ref<T[]>([])
  const total = ref(0)
  const loading = ref(false)
  const error = ref(false)

  async function refresh() { ... }
  function startPolling() { ... }
  function stopPolling() { ... }

  return { list, total, loading, error, refresh, startPolling, stopPolling }
}
```

### 5.2 消费方式

各模块组件通过 composable 获取数据，不直接依赖 store 的具体字段：

```typescript
// OrderDynamicModule.vue
const { list, total, loading, error, refresh } = useDynamicModule(
  () => dashboardStore.fetchOrderDynamic(),
  { pollingInterval: 300_000 },
)
```

### 5.3 接口切换成本

当后端契约确定后，只需修改 `api/provider/dashboard/index.ts` 中的 fetch 函数实现，composable 和组件层零改动。

### 6.2 详情页侧（detail.vue）

```typescript
// onMounted 或 watch(detail) 中
watch(detail, (val) => {
  if (!val || !route.hash) return
  nextTick(() => {
    const el = document.querySelector(route.hash)
    if (el) {
      el.scrollIntoView({ behavior: 'smooth', block: 'center' })
    }
    // v-if 区域可能未渲染，延迟重试一次
    if (!el) {
      setTimeout(() => {
        const retryEl = document.querySelector(route.hash)
        retryEl?.scrollIntoView({ behavior: 'smooth', block: 'center' })
      }, 500)
    }
  })
}, { immediate: true })
```

## 7. 轮询与刷新机制

### 7.1 自动轮询

- **触发**：onMounted 首次拉取完成后启动 setInterval
- **间隔**：300_000ms（5 分钟）
- **范围**：仅三模块（orderDynamic / afterSaleDynamic / opportunityRecommend）
- **清除**：onUnmounted + providerId 切换时

### 7.2 手动刷新

- 各模块标题栏右侧刷新图标，点击调用对应 refresh()
- 刷新期间图标旋转动画（CSS transition）
- 刷新不重置 list（避免闪烁），仅在成功后替换数据

### 7.3 主体切换

```typescript
watch(() => userStore.providerId, (newId, oldId) => {
  if (!newId || newId === oldId) return
  // 重置三模块 + 重新拉取
  resetDynamicModules()
  fetchAllDynamic()
})
```
