# REQ\-133 二级频道页二次优化\-技术方案

> **阶段归属说明（2026-11-23）**：本文件是团队技术方案输入，按原样保留，不替代正式产物 `阶段2-技术方案-REQ-133.md`。未确认的接口字段、文件边界、域名和设计细节继续按阶段 0/1 的 U 项跟踪；方案建议不视为外部确认。
目标仓库：wds\-miniapp

参考仓库：wds\-web\-channel、es\-app\-main

## **一、项目背景**



目前二级频道运行在 wds\-web\-channel，服务详情、服务商详情等核心业务能力来源于 es\-app\-main，登录和部分雇主端能力已经在 wds\-miniapp 中实现。

本次计划将 wds\-web\-channel 的整体功能迁移到 wds\-miniapp，由 wds\-miniapp 同时承载微信小程序和浏览器 H5，减少多仓库重复开发和维护成本。

迁移后的 H5 需要支持手机、iPad 竖屏、iPad 横屏及桌面浏览器。



## **二、项目目标**



- 将 wds\-web\-channel 的二级频道页面整体迁移到 wds\-miniapp。

- 将 es\-app\-main 中的雇主端服务详情迁移或复用到 wds\-miniapp H5。

- 将 es\-app\-main 中的服务商详情迁移或复用到 wds\-miniapp H5。

- 将需求留言和留资页面迁移或复用到 wds\-miniapp H5。

- 登录页面统一使用 wds\-miniapp 现有登录页面和登录态。

- 浏览器中，用户从二级频道或服务详情完成登录后，展示下载万大圣 App 的引导提示。

- 完成 iPad 横竖屏适配，保证页面不变形、不遮挡、不出现整页横向滚动。

- 迁移完成后，相关功能只在 wds\-miniapp 中继续迭代，避免两套实现长期并行。

## **三、功能来源与迁移原则**

### **1\. 二级频道**

二级频道以 wds\-web\-channel 为功能和内容结构来源。

主要参考目录：wds\-web\-channel/src/views/sub\-channel

频道接口继续使用：GET /v1/employer/category\-channels/\{slug\}

迁移到 wds\-miniapp 后，页面落在：src/pages/category\-channel

### **2\. 服务详情**

服务详情以 es\-app\-main 雇主端服务详情为交互、视觉结构和接口契约来源。

主要参考目录：es\-app\-main/lib/features/employer/service\_detail

wds\-miniapp 已经存在服务详情页面，后续应优先复用和补齐 H5、iPad 能力，不重新维护另一套页面。

### **3\. 服务商详情**

服务商详情以 es\-app\-main 雇主端服务商详情为交互、视觉结构和接口契约来源。

主要参考目录：es\-app\-main/lib/features/employer/supplier\_detail

wds\-miniapp 已经存在服务商详情页面，后续应优先复用和补齐 H5、iPad 能力。

### **4\. 需求留言和留资**

需求留言继续使用现有雇主留资接口。

从二级频道进入留资页时，需要携带当前频道的 categoryId，用于记录线索来源。

来源参数规则：sourceType 为 2，sourceCategoryId 为当前频道 categoryId，marketingSlotId 为 0。

### **5\. 登录**

登录统一使用 wds\-miniapp 现有登录页、auth Store 和会话体系。

不迁移 wds\-web\-channel 中的 LoginModal 登录弹窗。

微信小程序和 H5 共用登录业务逻辑，但 H5 不展示微信小程序专属的手机号授权按钮。

### **6\. Flutter 迁移原则**

只参考 es\-app\-main 的页面流程、接口契约、视觉结构和业务文案。

禁止逐行翻译 Flutter 的 Bloc、Widget、BuildContext、Scaffold 等原生机制。

所有页面统一使用 Taro 4、Vue 3、Pinia 和 wds\-miniapp 现有组件实现。

## **四、二级频道迁移范围**

二级频道需要支持以下模块：

- 顶部 Banner 轮播。

- 快捷分类入口。

- STANDARD 标准分类模式。

- IMAGE 图片分类模式。

- 智能体市场。

- 活动服务产品。

- 最新服务产品。

- 推荐服务产品。

- 行业资讯。

- 需求留言入口。

- 底部 Banner。

- 页面骨架屏。

- 网络错误、重试和空数据状态。

- 下拉刷新。

- 微信好友分享和朋友圈分享。

- H5 页面标题、SEO 描述和 canonical 地址。

- 页面、模块、商品、Banner、分类、资讯、留资和分享埋点。

wds\-web\-channel 中的 PC 顶部导航、登录弹窗和通知弹窗不直接复制。

迁移后统一使用 wds\-miniapp 的页面壳、路由、登录态和公共组件。

如果 H5 需要保留品牌页脚，只保留客服、备案和运营链接等必要内容，不能继续使用最小宽度 1080 像素的 PC 冻结布局。

## **五、服务详情范围**

服务详情使用 productId 加载数据。

游客可以浏览以下内容：

- 服务封面和图片。

- 服务标题和所属类目。

- 套餐、价格和优惠信息。

- 服务介绍、服务内容和交付标准。

- 服务案例和服务资质。

- 常见问题和服务评价。

- 服务商摘要。

以下操作需要登录：

- 联系卖家。

- 立即购买。

- 创建订单。

- 其他依赖雇主身份的操作。

用户登录成功后需要返回原服务详情，并保留 productId、套餐和来源参数。

点击服务商信息时进入服务商详情，并传递 providerId。

服务下架、参数缺失、无权限和网络失败时，需要展示明确状态，不能出现白屏或残缺内容。

## **六、服务商详情范围**

服务商详情使用 providerId 加载数据。

页面需要包含以下内容：

- 服务商名称、头像、认证信息、等级和标签。

- 公司或个人简介。

- 服务区域和主营类目。

- 在售服务列表和服务类目筛选。

- 服务案例及附件预览。

- 服务商评价。

- 分享入口和联系服务商入口。

服务商公开信息允许游客浏览，联系服务商等受保护操作需要先登录。

从服务商详情点击服务产品时，进入 wds\-miniapp 服务详情，不新增另一套详情页面。

## **七、需求留言和留资页**

表单包含以下字段：

- 姓名。

- 手机号。

- 企业名称。

- 公司行业。

- 需求类型。

- 需求描述。

手机号必填，并校验中国大陆 11 位手机号。其他字段按照现有接口契约选填。

提交时必须防止重复点击和重复创建线索。

提交成功后，根据接口返回的 openLoginDialog 决定是否引导用户登录，页面不能自行猜测登录时机。

## **八、登录统一方案**

微信小程序和 H5 均使用 wds\-miniapp 的登录页。

H5 使用现有手机号验证码或密码登录能力，不显示仅微信小程序支持的 getPhoneNumber 授权入口。

进入登录页前需要保存以下信息：

- 来源页面。

- 来源页面完整参数。

- 用户登录前准备执行的操作。

登录成功后优先返回来源页面。

已登录用户进入公开页面时，不重复要求登录。

登录、登出和 401 处理只能通过 auth Store 完成，频道页和详情页不能各自维护登录态。

## **九、浏览器登录后的下载引导**

### **1\. 展示范围**

下载引导只在浏览器 H5 中展示，微信小程序不展示。

用户从以下页面发起登录并成功返回时展示：

- 二级频道页面。

- 服务详情页面。

服务商详情和留资页默认不主动弹出下载引导。

### **2\. 触发流程**

游客进入二级频道或服务详情。

用户点击需要登录的功能。

页面跳转到 wds\-miniapp 登录页。

用户完成登录。

登录页恢复原页面和原始参数。

页面确认当前运行环境为 H5，并确认本次登录来源为二级频道或服务详情。

页面展示“下载万大圣 App”引导。

用户可以选择下载，也可以选择暂不下载并继续浏览当前页面。

### **3\. 展示规则**

- 只有本次明确的登录成功事件可以触发下载引导。

- 页面刷新、已有登录态进入和静默刷新 token 不触发。

- 同一次登录流程只展示一次。

- 用户关闭后，本次浏览器会话不重复展示。

- 用户下一次主动登录后可以重新展示。

- 下载失败或关闭提示不能影响已经完成的登录。

- 下载引导不能阻断用户继续浏览频道和服务详情。

### **4\. 引导内容**

下载引导至少包含以下内容：

- 标题。

- 简短的 App 能力说明。

- “下载万大圣 App”主按钮。

下载地址必须从环境配置读取，不能散落在页面代码中。

iPhone 和 iPad 进入 iOS 下载地址，Android 设备进入 Android 下载地址，无法识别平台时进入统一下载落地页。

建议由登录页生成一次性登录事件标记，标记中包含登录事件 ID 和来源页面。来源页面消费后立即清除。

禁止通过持续监听 isAuthenticated 直接弹出下载引导，否则页面初始化、刷新用户资料和切换身份都可能误触发。

## **十、H5 路由和外链兼容**

### **1\. 内部路由**

二级频道路由：/pages/category\-channel/index

二级频道参数：slug，可选 categoryId

服务详情路由：/pages/service\-detail/index

服务详情参数：productId

服务商详情路由：/pages/supplier\-detail/index

服务商详情参数：providerId

需求留言路由：/pages/demand\-inquiry/index

需求留言参数：sourceCategoryId，可选 marketingSlotId

登录路由：/pages/login/index

所有站内跳转必须使用 Routes 和统一 navigateTo 方法，不能在页面中手工拼接内部路由。

### **2\. 频道公开地址**

频道外部地址继续兼容以下格式：

https://channel\.wdsheng\.com/:slug?categoryId=:categoryId

发布 H5 时，由网关或 CDN 将频道域名和历史深链回源到 wds\-miniapp H5 入口。

用户直接粘贴链接、刷新页面、前进和后退时都必须正常打开对应频道，不能只支持站内点击跳转。

### **3\. 历史链接**

服务详情和服务商详情需要保留当前线上历史链接解析规则。

历史地址统一转换为 productId 或 providerId 后，再进入 wds\-miniapp 页面。

旧链接下线前，需要通过访问日志确认已经没有有效流量。

## **十一、频道跳转规则**

频道运营配置中的链接可以跳转到以下目标：

- 二级频道。

- 服务详情。

- 服务大厅和服务类目筛选结果。

- 智能体会话。

- 活动中心。

- 需求留言。

- 允许的站内 WebView。

- 可信外部链接。

未知链接需要提示“暂无法打开该链接”，不能将任意未知地址直接交给 WebView。

## **十二、iPad 和响应式适配**

### **1\. 手机布局**

适用宽度：小于 768 像素。

页面采用单列布局，商品列表默认双列，底部操作栏占满页面宽度并处理底部安全区。

### **2\. iPad 竖屏布局**

适用宽度：768 到 1023 像素。

内容区域居中显示，建议最大宽度为 720 像素。

商品列表根据卡片最小宽度显示 2 到 3 列。

登录表单、购买面板和弹层限制最大宽度并居中显示。

### **3\. iPad 横屏和桌面布局**

适用宽度：1024 像素及以上。

内容区域居中显示，建议最大宽度为 1180 到 1200 像素。

服务详情可以使用主内容和辅助信息双栏布局，频道商品列表根据可用宽度自适应列数。

### **4\. iPad 验收尺寸**

- 768 × 1024。

- 810 × 1080。

- 820 × 1180。

- 834 × 1194。

- 1024 × 768。

- 1180 × 820。

- 1366 × 1024。

### **5\. iPad 专项要求**

- 横竖屏切换后不刷新页面。

- 横竖屏切换后重新计算列表列数、图片轮播和弹层高度。

- 页面适配顶部和底部安全区。

- 底部购买和联系按钮不能被 Home Indicator 遮挡。

- 主要点击区域不小于 44 × 44 CSS 像素。

- 不能只依赖鼠标 hover 表达交互状态。

- 图片保持正确比例，不能在横屏时被拉伸。

- 长标题、服务商名称和价格需要正确换行或省略。

- 页面不能设置最小宽度 1080 像素。

- 所有目标尺寸都不能出现整页横向滚动条。

- 输入框唤起和关闭软键盘后，提交按钮和底部操作栏仍然可见。

- 布局判断使用 CSS 视口和媒体查询，不能依赖固定设备型号。

## **十三、H5 页面要求**

- H5 使用浏览器历史栈。

- 支持浏览器前进、后退、刷新和深链直接打开。

- H5 不显示微信小程序专属分享按钮。

- H5 不调用微信小程序 open\-type 能力。

- 页面标题、SEO 描述、关键词和 canonical 地址优先使用频道接口返回内容。

- SEO 内容缺失时回退到频道名称，不能写死某个具体频道。

## **十四、工程实现要求**

页面调用链继续遵守以下分层：页面层调用 Store，Store 调用 Service，Service 调用 services/core 请求层，请求层再使用 config 和 storage 等基础设施。

具体要求如下：

- 页面不能直接调用 Taro\.request。

- 页面不能直接读写登录 storage。

- 接口路径统一登记在 ApiEndpoints。

- 游客接口统一登记在 PUBLIC\_PATHS。

- 动态频道公开路径只能使用受控前缀匹配。

- DTO 必须通过 mapper 转换成页面模型。

- 运营配置字段需要兼容缺省值和空数组。

- 不改变现有 401、并发、公共请求头和信封解析策略。

## **十六、实施顺序**

1. 确认路由、域名、公开接口和历史链接兼容范围。

2. 完成频道 DTO、mapper、Service、Store 和页面模块迁移。

3. 接通频道商品、类目、活动、智能体、资讯和留资跳转。

4. 对服务详情、服务商详情和留资页补齐 H5 展示和返回行为。

5. 完成手机、iPad 竖屏、iPad 横屏和桌面布局。

6. 接入统一登录返回流程和下载引导。

7. 完成 SEO、分享、埋点、错误态和性能优化。

8. 灰度切换 channel\.wdsheng\.com，并保留旧站快速回滚能力。

## **十七、验收标准**

### **1\. 功能验收**

- 任意有效 slug 可以通过外部 URL 直接打开对应频道。

- 页面刷新后频道参数和内容不丢失。

- 频道模块根据接口数据正确显示和隐藏，接口空字段不会导致白屏。

- 商品可以进入正确的服务详情。

- 服务商入口可以进入正确的服务商详情。

- 留资提交携带正确的 sourceType 和 sourceCategoryId。

- 游客可以浏览公开内容。

- 受保护操作会进入 wds\-miniapp 登录页。

- 登录成功后可以返回原页面并恢复参数。

- 浏览器从频道或服务详情完成登录后，只展示一次下载引导。

- 微信小程序中不展示下载引导。

- 浏览器前进、后退、刷新、复制链接和多标签打开正常。

### **2\. 视觉验收**

- 手机、iPad 和桌面浏览器没有整页横向滚动。

- iPad 横竖屏切换没有错位、遮挡和内容丢失。

- 固定底栏、弹层和输入区域正确处理安全区和软键盘。

- 服务卡片、Banner、详情图片和文字在各断点下比例稳定。

### **3\. 工程验收**

- pnpm type\-check 通过。

- pnpm lint 通过。

- pnpm build:h5:test 通过。

- pnpm build:weapp:test 通过。

- 微信开发者工具完成小程序回归。

- Safari、Chrome 和 iPad Safari 完成 H5 验收。

- 不输出或提交 src/config/index\.ts 中的任何密钥值。

## **十八、上线和回滚**

先发布 wds\-miniapp H5 静态产物，再灰度调整频道域名回源。

灰度期间需要关注页面加载成功率、接口失败率、登录成功率、下载引导曝光和点击、下载引导关闭以及留资转化率

灰度期间保留旧 wds\-web\-channel 产物和原域名回源配置。

出现大面积白屏、深链 404、登录回跳失败或核心接口异常时，可以快速切回旧站。

灰度稳定后停止旧仓库业务迭代。历史链接和 SEO 收录迁移完成后，再安排旧站下线。
