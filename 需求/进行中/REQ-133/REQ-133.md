## 一、项目概况

- **需求目标**：企服货主端二级频道页（`/category-channel/:slug`）适配 H5 浏览器与 APP 内 WebView 双容器；运管后台二级频道配置增加「H5 跳转链接」与「最新服务行数」配置能力。
- **涉及仓库与基线**（核对 2026-11-26）：
  | 仓库 | 分支 | 基线 | 提交状态 |
  |---|---|---|---|
  | `wds/wds-miniapp`（Taro 4.3 + Vue3，频道页本体） | `F-REQ-133` | `126fce7` | **已提交并推送**（`cf5b138`、`126fce7`）；mock 删除未提交 |
  | `wds/wds-admin-web`（Vue3 + TS，运管配置侧） | `F-REQ-133` | `4f436cc7` | **已提交并推送**，工作区干净 |
  | `wds/wds-web-channel`（PC 频道站） | — | — | 仅作契约参考，本期零改动 |
  | `wds/es-app-main`（Flutter APP） | — | — | 只读参考，桥接契约见其 `docs/integrations/h5/h5-integration-guide.md` |
- **功能分支**：两仓同名 `F-REQ-133`，均已推 origin，接手 `git pull` 该分支即可开工。
- **范围边界**：本文只覆盖 miniapp 频道页与 admin-web 配置侧；其余端/页面不在本仓范围，勿重复开发。

## 四、核心文件说明

| 文件 | 职责与扩展点 |
|---|---|
| `miniapp utils/category-channel-jump.ts` | 频道所有运营链接出口。新增站内目的地→改 `employer-marketing-jump.ts` 的 destinations 单点；**不要**在组件内自写跳转 |
| `miniapp utils/app-bridge.ts` | 容器桥唯一入口。原生能力调用一律 `getAppBridge()` + 特性检测 + try/catch；新深链 path 须 APP 端登记后替换 TODO |
| `miniapp utils/router.ts` | `requireLoginForCurrentPage`（同步门禁）与 `openLoginForCurrentPage`（登录出口+容器分流）。加门禁点只接前者，不得复制函数体 |
| `miniapp config/endpoints.ts` + `services/core/request.ts` | 游客放行口径单点：新增免鉴权读接口加前缀/精确路径；**写接口不得加入** |
| `miniapp types/category-channel.ts` | DTO↔模型唯一映射层；**h5Url 镜像未落地**：落地时在此加镜像与 mapper，字段名与 admin-web 线上接口一致 |
| `miniapp pages/category-channel/index.vue` | 模块编排与门禁接线；顶栏吸顶结构 `.top > (AppOpenBanner + EsNavBar)`，内层 es-nav 静态覆写限定 `.top` 祖先内 |
| `admin-web components/ChannelLinkField.vue` | H5 第二字段单点；新模块接 H5 只需绑 `h5Url` + `update:h5Url` |
| `admin-web api/secondary-channel/config-mapper.ts` | 提交/回显双向咽喉；字段改名定向替换此处 + api-types |
