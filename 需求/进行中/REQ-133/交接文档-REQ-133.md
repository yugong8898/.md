## 六、注意事项

### 6.1 跨端与容器

- Taro H5 的页面滚动层是 `.taro_page`，**不是 window**；写滚动探针/锚点逻辑时取 `.taro_page || document.scrollingElement`。
- `scroll-view` 自身即滚动层：内边距加在内层内容节点，加在 scroll-view 宿主上不生效。
- swiper `circular` 会生成克隆片：自动化点击/断言须按**视口可见片**定位，nth(0) 可能是末项克隆（空链接）。
- weapp 无 `URLSearchParams`：链接解析用手写 splitUrl/readQuery，勿引浏览器 API。
- 容器桥调用必须特性检测 + try/catch：桥缺失、方法未登记（`{ok:false}`/reject）都要降级 H5 路径。
- APP 容器 Cookie 只注入 `*.wdsheng.com` 子域：随机外链可打开但**不带登录态**，属运营配置责任，前端不做白名单拦截。
- 端差异用编译期常量（IS_H5/IS_WEAPP）或条件编译，不做运行时 UA 串判断扩散。

### 6.2 登录与门禁

- 门禁矩阵是裁决终态：**只**在 banner×2、类目两档、留资聚焦/提交挂门禁；服务卡/资讯/智能体/查看更多直跳，不要"顺手补全"。
- 登录成功回频道页不续跳原目标（returnTo 只回页面）；留资提交另有服务端 `openLoginDialog` 兜底（双保险，勿删）。
- 已知可接受行为：未登录聚焦输入框键盘可能瞬现再随跳页收起。
- 容器登录中间态：原生登录回 H5 仍游客（待定 6 落地前），联调时勿误判为门禁 bug。

### 6.3 样式与 UI

- 频道页样式用 **px（375 设计基线）**，与仓内 rpx 页面混存，改样式时跟随本页面域口径。
- 类名裸短名 + 严格 SCSS 嵌套（子选择器防串污）；新增样式块禁止平铺独立选择器。
- 顶栏吸顶只认 `.top` wrapper；给 EsNavBar 恢复 sticky 会与指引条重叠吸到同一点。
- 截断统一纯 CSS clamp + break-all；不要再加 JS 测高/延迟补偿类逻辑（历史实验已回退）。
- 图片接口若返回 OSS path 需经转换层，勿直绑（本频道 DTO 为完整 URL，留资二维码为本地静态资源）。

### 6.4 验证与环境

- miniapp 门禁：ESLint 须 exit=0；`vue-tsc` 存量基线 **4 条**（config/h5-dev-proxy TS2307 + services/agent-chat TS2339×3），只核零新增，不修历史。

- Node 环境：Taro 4.3 要求 ≥20；**weapp 构建需 arm64 Node 20**（x64 v20 swc binding 不匹配、v22 strip-types 与 enum 冲突），环境未就绪前构建证据记"未验证"。
- H5 dev：`npm run dev:h5`，:10086，hash 路由；探针注入 mock 用路由拦截改 model，注意资讯 DTO 字段为 `industryNews`。
