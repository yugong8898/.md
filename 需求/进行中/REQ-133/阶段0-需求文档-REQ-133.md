## 需求概况

- **需求编号**：REQ-133
- **需求名称**：二级频道适配 APP 端 / H5 浏览器（原始文档标题：REQ-133 二级频道适配APP端_H5浏览器）
- **需求版本**：R0（初始版）
- **复杂度判定**：**完整档**（多端 × 多模块 × 新接口新字段 × 运管后台配置链路）—— 按 `wlyd-requirement-change-analysis` 输出分级，十章全部填实。
- **需求来源**：`.md/需求/进行中/REQ-133/原始需求/REQ-133 二级频道适配APP端_H5浏览器.md`（含 60 余张截图附件）
- **落地基座（唯一）**：`wds/wds-miniapp`（Taro 4.3 + Vue 3.5，微信小程序 + H5 双端编译）。本期全部代码改动落在该仓库，在现有 `pages / components / store / services / config` 分层上扩展开发。
- **参考项目**：`wds/wds-web-channel`（PC 二级频道页 `/:slug`），**本期零改动**，仅作频道配置数据契约 / 模块顺序 / 视觉参考。
- **本期目标**：一套响应式 H5 覆盖手机浏览器与 APP 内 WebView，适配二级频道页、服务详情页、服务商详情页，购买 / 咨询 / 留资衔接注册引导；补齐运管后台后缀管理与服务产品展示行数配置。
- **页面形态**：在 `wds-miniapp` 内新建原生二级频道页，复用 `pages/home` 布局骨架与通用积木组装；不采用 web-view 承载 PC H5（PC 冻结 1080px，与手机端模块顺序冲突）。
- **交付端口径**：代码在 `wds-miniapp` 一处开发，Taro 天然编译出 weapp / h5 两份产物；本期验收按 R-025 与需求 L89 以**手机端（移动浏览器 + APP WebView 各一轮）**为准，小程序端不单列专项适配与验收项；APP WebView 内嵌 `build:h5` 产物。
- **本期排除**：埋点上报层（6 事件 / `channel_suffix` / APlus）、按后缀维度的访问统计与运管后台统计报表、数据侧后缀解析与事件采集。
- **本阶段边界**：只做需求视角的规则拆解、范围盘点、待确认项登记与改动清单，**不改代码、不做技术方案**（阶段 1 / 2 处理）。

## 业务规则与边界条件

1. **双端统一基准**：移动端浏览器与 APP 内嵌共用同一套响应式 H5，视觉交互以 APP 端实现为参照；产品卡、资讯卡字段与业务规则与 PC 一致，仅做排版与触控适配（L224）。
2. **留资两种触发来源必须区分**：移动浏览器场景「提交成功后引导注册 WAP」；APP WebView 场景「按登录态分流，未登录先登录再自动提交并暂存表单」（L364-368 vs L449-457）。两者公式相近但交互结果不同，不得合并为一个处理逻辑。
3. **购买类动作与登录校验口径冲突**：L324/L326/L419/L421 要求引导注册 WAP，L277 要求按 PC 现有登录校验，L578 验收写「按既定登录规则跳转」。同一批动作三种表述，需产品裁决（U-007）。
4. **底部模块口径**：L253 表格与 L465-467 为双端隐藏，L384「仅作用于移动端浏览器场景」为旧口径残留；需明确「底部模块＝页脚 footer」，不含底部通栏 Banner 与需求留言模块（运管后台表格 L497-498 已区分二者）。
5. **行数边界**：配置非法 / 未配置按默认行数渲染；商品不足按实际数量；配置值范围建议 1-10；默认值待评审。
6. **降级边界**：APP 桥接能力缺失时降级为 H5 行为，页面仍可浏览与跳转；模块级失败重试只重取当前失败模块。
7. **后缀链接用途**：本期保留「后缀配置 + 带后缀链接生成」能力，但用途与验收方式待产品确认（U-018），不写进本期验收项。

## 二、业务规则

### 2.1 字段规则

| 字段 / 参数 | 口径 | 状态 |
|---|---|---|
| `slug` | 频道访问路径标识，用户端按 slug 查询当前生效的已发布频道页 | `wds-web-channel` 已有；`wds-miniapp` 无 |
| `suffix`（URL 参数） | 带后缀链接的访问标识，前端只消费、不做统计 | 用途与验收方式待确认（U-018） |
| 展示行数 | 正整数，建议 1-10；实际卡片数 = 行数 × 当前端每行卡片数（移动端 2） | 默认值与字段落点待评审（U-014） |
| `openLoginDialog` | 现网留资接口返回，决定提交成功后是否弹登录；移动端 PRD 改为「统一引导注册」 | 代码事实已验证，处置待裁决（U-008） |

### 2.2 初始化规则

- 频道页按 slug 拉取当前生效的已发布配置；模块顺序与 PC 一致；接口在 `wds-miniapp` 侧按自身网关前缀登记。
- APP WebView 场景优先复用容器登录态与原生导航栏，桥接缺失时降级 H5 行为。

### 2.3 联动规则

- 行数配置 → 卡片渲染数量（Web / H5 / APP 同步生效）。
- 后缀配置 → 带后缀链接 → 页面读取（本期止于链接生成，无统计链路）。
- 购买 / 联系 / 选择数量 / 客服 / 服务商详情入口 → 注册引导 → 注册成功 → 下载 APP 引导。
- 留资提交 → 按端型与登录态分流（浏览器统一注册引导 / APP 登录后自动提交）。

### 2.4 校验规则

- 展示行数非法 / 未配置按默认值，不阻断页面；商品不足按实际渲染，不补空位。
- 留资表单校验通过才提交；提交失败保留已填内容；APP 未登录取消登录返回时表单内容保留。
- 图片按容器等比缩放、统一渲染高度、失败占位；页面禁止横向滚动条。
