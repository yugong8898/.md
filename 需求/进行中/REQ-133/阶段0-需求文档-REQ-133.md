## 需求概况

> **当前结论（2026-11-23）**：本文件是阶段 0 的需求基线，不代表待确认事项已获业务确认。来源文档明确的内容按已知需求记录；冲突或缺少外部输入的内容列入 U 项，由对应确认方跟进。阶段文档整理完成，不等于阶段门禁通过。

- **需求编号**：REQ-133
- **需求名称**：二级频道页二次优化（原始需求标题：REQ-133 二级频道适配APP端_H5浏览器）
- **需求版本**：R3（R0 初始版；R1 APP 登录态 Cookie-only；R2 责任范围及打开 APP 链接规则调整；R3 补充移动端 H5 整页与顶部打开 APP 设计稿基线及模块级 UI 规则）
- **复杂度判定**：**完整档**（多端 × 多模块 × 新接口新字段 × 运管后台配置链路 × 合作开发分工）—— 按 `wlyd-requirement-change-analysis` 输出分级，十章全部填实。
- **需求来源**：`原始需求/REQ-133 二级频道适配APP端_H5浏览器.md`（含 60 余张截图）、`REQ-133 二级频道页二次优化-功能清单.md`、`REQ-133 二级频道页二次优化-技术方案.md`
- **代码落地范围**：二级频道新页面与顶部打开 APP 组件落在 `wds/wds-miniapp`；运管后台新增 H5 跳转链接属于本人负责，但目标后台仓库未定位，需确认后纳入跨仓工作区。
- **参考项目**：`wds/wds-web-channel`（PC 二级频道页 `/:slug`，**本期零改动**，仅作频道配置 DTO / 模块顺序 / 视觉参考）；`wds/es-app-main`（Flutter 雇主端，服务详情 / 服务商详情的交互与接口契约来源，并承载 H5 容器桥接文档）。
- **本期目标**：把二级频道能力迁移进 `wds-miniapp` H5，登录统一走 miniapp 现有登录页与 auth Store，浏览器中完成登录后引导下载万大圣 App；频道配置链接在 APP 与 H5 可用；运管后台展示行数配置对新页面生效；H5 覆盖手机、iPad 竖屏 / 横屏与桌面浏览器。
- **页面形态**：`src/pages/category-channel`（团队技术方案定名），路由 `/pages/category-channel/index`，参数 `slug` + 可选 `categoryId`。不采用 web-view 承载 PC H5（PC 冻结 1080px，与手机端模块顺序冲突）。
- **交付端口径**：同一套代码由 Taro 编译 weapp + h5 两份产物。**不新建小程序原生频道页**；H5 链接会在微信内被打开，需保证微信内置浏览器可用；小程序端只做回归，不单列专项适配与验收项。
- **本期排除**：埋点上报层与埋点工具、按后缀维度的访问统计与运管后台统计报表、数据侧后缀解析与事件采集、`wds-web-channel` 整仓改动、小程序端专项频道页开发。
- **合作开发**：功能清单按人分工，本工作流**只跟踪王新骏负责的条目**，合作方条目仅保留协作接口边界，见下一章。
- **本阶段边界**：只做需求视角的规则拆解、范围盘点、待确认项登记与改动清单，**不改代码**。
- **需求版本 R1 补充（2026-11-23）**：部分页面可能在 APP 中直接使用；此类页面登录态必须与 APP 保持一致，已确认通过 Cookie 读取 `Authorization` / `ct`，忽略 `localStorage`。
> **需求版本 R2 补充（2026-11-23）**：本人负责二级频道新页面、页面顶部「打开 APP」组件及运营管理后台新增 H5 跳转链接能力。Android 下载地址为 `https://a.app.qq.com/o/simple.jsp?pkgname=com.wlit.esp`，iOS 下载地址为 `https://apps.apple.com/cn/app/id6795848056`；APP 唤起 scheme 为 `wdsheng://open/<path>`，`<path>` 必须 URL encode。

> **需求版本 R3 补充（2026-11-23）**：用户提供两个设计稿直链——二级频道移动端 H5 整页 `175570-262826`、顶部打开 APP 指引条 `175975-30231`，并附模块级 UI 标注截图（banner / 类目区 / 智能体市场 / 活动服务产品 / 通用商品卡 / 行业资讯）。据此新增 R-022~R-027 设计 UI 规则；U-002 顶部横条形态、U-008 移动端整页与顶部组件设计稿缺口收敛为部分确认；新增 U-014（类目区 2 个类目布局）、U-015（顶部指引条展示范围）。

### A. 本人范围规则

| 编号 | 规则 | 落点 / 依据 |
|---|---|---|
| R-001 | 登录统一使用 `wds-miniapp` 现有登录页、auth Store 与会话体系，不迁移 PC 的 LoginModal；H5 使用手机号验证码或密码登录，不展示微信小程序专属的 `getPhoneNumber` 授权入口 | 技术方案第八 / 十五章；`pages/login/index.vue` |
| R-002 | 进入登录页前保存来源页面、来源页面完整参数、登录前待执行操作；登录成功后优先返回来源页并恢复参数；已登录用户进入公开页面不重复要求登录 | 技术方案第八章 |
| R-003 | 登录、登出与 401 只能通过 auth Store 完成，频道页与详情页不各自维护登录态 | 技术方案第八章；项目分层铁律 |
| R-004 | 浏览器 H5 中，从二级频道或服务详情发起登录并成功返回时展示「下载万大圣 App」引导；微信小程序不展示；服务商详情与留资页是否展示见 U-001 | 技术方案第九章；功能清单 L18 |

## 业务规则与边界条件

1. **登录口径**：统一使用 miniapp 现有登录页，不迁移 PC 登录弹窗；「注册」由登录页的注册分支与未注册手机号自动建号承接，不另建 WAP 注册页。
2. **下载引导触发边界**：只有本次明确的登录成功事件可触发，且只在 H5、只从二级频道或服务详情返回时触发；页面刷新、已有登录态、静默刷新 token 均不触发。服务商详情是否参与触发见 U-001。
3. **留资来源边界**：从频道页进入留资时传 `sourceCategoryId`（当前频道 `categoryId`），`sourceType` 由 `resolveInquirySource` 推导为 2、`marketingSlotId` 为 `'0'`；提交后的引导完全由 `openLoginDialog` 决定。
4. **跳转安全边界**：未知链接必须提示后终止，不能把任意未知地址交给 WebView；可信外链需域校验，不能沿用「任意 http(s) 直接进 webview」的现状。
5. **行数边界**：非法 / 未配置按默认值且不阻断页面；商品不足按实际数量渲染不补空位；Web 与移动端每行卡片数不同，需同一配置源。
6. **响应式边界**：横竖屏切换不刷新页面；页面不设置 `min-width: 1080px`；所有验收尺寸都不能出现整页横向滚动条。
7. **双端边界**：小程序不新建原生频道页、不展示下载引导；H5 链接在微信内打开必须可用；APP 内嵌时容器标识以 `es-app-main` 桥接文档为准，识别失败降级为普通 H5 行为。

### 2.2 初始化规则

- 频道页按 `slug` 拉取当前生效的已发布配置；接口在 miniapp 侧按 `/gateway/...` 前缀登记，不照抄 PC 路径。
- 登录页进入前保存来源页与参数；登录成功后由 `finishLogin` 恢复，消费一次性登录事件标记后立即清除。
- APP 内嵌时从 Cookie 读取 `Authorization` / `ct` 以与 APP 登录态一致，忽略 `localStorage`；Cookie 属性、缺失/过期与登出处理见 U-013。

### 2.3 联动规则

- 频道配置链接 → 白名单解析 → 站内 `Routes` / 可信外链 WebView / 未知链接提示终止。
- 登录成功 → 一次性事件标记 → 来源页消费 → 浏览器展示下载引导 → 关闭后本会话不再展示。
- 行数配置 → 卡片渲染数量（Web / H5 / APP 同步生效）。
- 服务商详情点击服务产品 → miniapp 服务详情，不新增详情页。

### 2.4 校验规则

- 留资手机号必填且校验中国大陆 11 位手机号；提交防重复点击与重复建线索；提交成功后按 `openLoginDialog` 决定引导。
- 未知链接提示后终止，不交给 WebView；可信外链需域校验。
- 运营配置字段兼容缺省值与空数组，接口空字段不导致白屏。
- 行数非法 / 未配置按默认值；商品不足按实际渲染不补空位；页面禁止整页横向滚动。
