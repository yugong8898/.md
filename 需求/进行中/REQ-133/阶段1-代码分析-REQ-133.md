- 登录门闩：`openLogin()` / `openLoginForCurrentPage()`（带 `returnTo`）/ `promptLogin()`（`watch(auth.isAuthenticated)` + `LOGIN_GATE_CLOSED` 事件，成功 resolve true、取消 resolve false）/ `finishLogin(returnTo)`（按 Tab / 页面栈决定是否 `navigateBack` / `switchTab` / `redirectTo`）/ `replaceWithLogin()`（分享冷启动用 redirect）。
- 登录页 `pages/login/index.vue`（1350 行）内含注册、短信注册、密码设置、忘记密码、未注册手机号自动建号；`endpoints.ts` 有 `userRegistration` / `sendRegistrationSmsCode` 且都在 `PUBLIC_PATHS`。
- **新增频道页需同步**：`app.config.ts` 的 `pages` 或 `subPackages`、`router.ts` 的 `Routes` 常量；若频道页要做登录回跳，`finishLogin` 的 `Object.values(Routes)` 白名单（L304）会自动覆盖新路由，无需单独改。

### 3.4 留资链路（`pages/demand-inquiry/index.vue`，299 行）

- L165-191 `submit()`：校验手机号 → `createEmployerInquiry({...source, employerId, mobile, name, companyName, industry, description, categoryId})` → `submitted = true`、清空手机号 → `if (result.openLoginDialog && !token && !auth.isAuthenticated) await openLoginForCurrentPage()`。
