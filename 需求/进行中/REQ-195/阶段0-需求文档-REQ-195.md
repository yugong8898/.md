## 需求规则清单

### R-001 统一名称
- **规则**：全端统一使用"电子合同签章认证"作为功能名称
- **影响**：所有页面文案、弹窗标题、消息标题等

### R-002 协议链接适配
- **规则**：电子合同签章认证流程中的协议为链接，前端需要适配协议展示
- **影响**：认证页面需支持协议链接渲染

### R-003 合同列表只展示待操作
- **规则**：服务商端合同管理、雇主端我的合同，只展示待操作的电子合同签章认证动作，认证成功不展示操作
- **影响**：合同列表页增加认证状态过滤

### R-004 固定入口位置（PC，6处）
| 编号 | 角色 | 端 | 页面 | 位置 |
|------|------|-----|------|------|
| R-004-1 | 雇主 | PC | 我的合同 | 页面顶部 |
| R-004-2 | 雇主 | PC | 我的 | 认证信息上方 |
| R-004-3 | 服务商 | PC | 合同管理 | 页面顶部 |
| R-004-4 | 服务商 | PC | 个人中心 | 认证信息上方 |
| R-004-5 | 服务商 | PC | 工作台 | 重要商机推荐上方 |
| R-004-6 | 供应商 | PC | 个人中心 | 页面内（待确认具体位置） |

### R-005 入口状态（6种）
| 状态 | 行为 |
|------|------|
| 去认证 | 可点击，进入认证流程 |
| 继续认证 | 可点击，继续未完成认证 |
| 审核中 | 不可点击 |
| 重新上传 | 可点击，重新上传授权委托书 |
| 重新认证 | 可点击，重新认证（到期后） |
| 认证成功 | 合同相关入口不显示 |

### R-006 入口显示规则
- **R-006-1**：仅对已完成平台实名认证且具备主体认证权限的用户展示
- **R-006-2**：存在以下任一情况时展示入口：
  - 尚未完成爱签电子签章认证
  - 已发起认证但尚未完成
  - 授权委托书正在人工审核
  - 授权委托书审核未通过
  - 电子签章认证授权已过期
- **R-006-3**：无主体认证权限的用户不展示入口
- **R-006-4**：认证状态以主体为唯一维度，同一主体在雇主、服务商、供应商及 WEB 端之间共享
- **R-006-5**：同一主体通过任一角色完成认证后，其他角色同步更新为认证成功
- **R-006-6**：“认证成功”状态在同一主体下全局仅曝光一次；刷新、再次进入页面或切换至其他角色后，入口不再展示
- **R-006-7**：同一账号下存在多个主体时，各主体独立判断认证状态，互不影响
- **R-006-8**：电子签章认证授权有效期为一年；到期后入口重新展示“重新认证”

### R-007 认证场景流程（在现有流程中插入新环节）

两端认证页均通过 `ViewType` 状态机切换步骤组件，本次在“签署协议”之前插入「电子签名认证」环节。

| 角色 | 端 | 现有流程 | 本次新增环节 |
|------|-----|---------|------------|
| 个人 | 服务商 | 提交材料 → 人脸认证 → 签署协议 → 系统审核 | 在“人脸认证”与“签署协议”之间插入「电子签名认证」 |
| 个体/企业法人 | 服务商 | 提交材料 → 完善信息 → 签署协议 → 系统审核 | 在“完善信息”与“签署协议”之间插入「电子签名认证」 |
| 个体/企业经办人 | 服务商 | 同上 | 在“完善信息”与「电子签名认证」之间插入「授权委托书上传+人工审核」 |
| 个人 | 雇主 | 提交材料 → 人脸认证 → 签署协议 | 在“人脸认证”与“签署协议”之间插入「电子签名认证」 |
| 企业法人 | 雇主 | 提交材料 → 签署协议 | 在“提交材料”与“签署协议”之间插入「电子签名认证」 |

> 注：雇主端无经办人角色，不需要授权委托书上传环节。`ElectronicSign.vue` 组件可跨两端复用。

**补充设计图**：[电子签章认证与授权委托书流程](./原始需求/图片和附件/电子签章认证与授权委托书流程.png)。图中确认：个人 / 法人的电子签章认证可在合同页以弹窗承载；经办人需先在弹窗中下载并上传授权委托书，之后进入人工审核结果页。

### R-008 签署合同场景流程
- **R-008-1** 未完成电子签章认证：
  - 个人/法人：拉起电子签名认证弹窗
  - 经办人：拉起授权委托书补充弹窗，审核通过后继续电子签章认证
- **R-008-2** 电子签章认证有效：全部主体直接进入合同签署
- **R-008-3** 电子签章认证已到期：
  - 个人/法人：重新拉起电子签名认证弹窗
  - 经办人：重新补充授权委托书，审核通过后重新进行电子签章认证
- **R-008-4** 注意事项：
  - 用户关闭弹窗后留在当前合同页面，不进入签署
  - 认证完成后点击通知消息自动返回原合同继续签署
  - 人工审核期间不能继续签署
  - 审核通过后用户再次进入合同，点击"立即签署"，自动进入下一流程

**补充设计图**：[认证协议与委托书审核结果](./原始需求/图片和附件/认证协议与委托书审核结果.png)。图中确认：个人认证为完整步骤页；经办人审核中、审核不通过均有独立结果态，审核不通过提供“重新上传”操作。

### R-009 认证页逻辑
- **R-009-1** 新增“03电子签名认证”环节
- **R-009-2** 页面样式：
  - 协议正文默认定位在顶部
  - 页面底部显示轻提示："请向下滑动并完整阅读协议"
  - 用户首次滑动协议正文后：阅读提示消失，"获取验证码"按钮开始3秒倒计时
  - 倒计时期间按钮不可点击，显示"3s后可获取"→"2s后可获取"→"1s后可获取"
  - 倒计时结束后，"获取验证码"按钮变为可点击
  - 用户未滑动协议时，不启动倒计时，不能获取验证码
  - 页面不向用户表达"阅读3秒即视为完整阅读"，3秒仅作为获取验证码前的交互等待时间
- **R-009-3** 手机号验证码规则：
  - 系统自动读取个人实名认证使用的手机号
  - 页面仅展示脱敏手机号（如 138****8888）
  - 当前页面不提供修改手机号入口
  - 用户点击“获取验证码”后，向该手机号发送验证码
  - 验证码发送成功后，按钮进入重新获取倒计时
  - 用户输入验证码前，“下一步”按钮不可点击
  - 用户输入完整验证码后，“下一步”按钮变为可点击
- **R-009-4** 提交与校验：
  - 验证码正确：完成电子签章认证，进入“签署协议”步骤
  - 验证码错误：停留当前页，提示“验证码错误，请重新输入”，修改后可再次提交
  - 提交中按钮不可重复点击
- **R-009-5** 返回规则：
  - 遵循原页面返回规则
  - 本次电子签名认证未完成，不记录为认证成功，再次进入仍需完成协议阅读和手机号验证

### R-010 经办人差异（仅服务商端）
- **R-010-1** 进入电子签名认证前，需先补充新版授权委托书并通过爱签人工审核
- **R-010-2** 无论新老用户均需重新下载新委托书并上传
- **R-010-3** 上传后经人工审核通过方可进入电子签名认证服务协议页面
- **R-010-4** 等待审核阶段可退出当前流程
- **R-010-5** 审核通过后发送站内信+push，点击通知或原流程可进入结果页（驳回）或协议页面（通过），后续流程一致
- **R-010-6** 授权委托书支持 PDF、JPG、PNG 格式，单文件不超过 20MB（来源：补充设计图）

### R-011 到期重新认证
- **规则**：到期情况同已认证用户电子签章认证流程一致，页面中文字提示及标题不一致，具体参考设计稿

### R-012 消息通知（6种时机）

## 业务规则与边界条件

### 认证状态枚举
| 状态值 | 含义 | 入口展示 | 可操作 |
|--------|------|---------|--------|
| 未认证 | 从未发起认证 | 去认证 | 是 |
| 认证中 | 已发起但未完成 | 继续认证 | 是 |
| 审核中 | 授权委托书人工审核中 | 审核中 | 否 |
| 审核未通过 | 授权委托书被驳回 | 重新上传 | 是 |
| 已认证 | 认证成功且在有效期内 | 不展示 | - |
| 已过期 | 认证成功但超过一年 | 重新认证 | 是 |

### 主体维度规则
- 认证状态以**主体**为唯一维度，不以账号或角色为维度
- 同一主体跨角色（雇主/服务商/供应商）、跨 WEB 端共享认证状态
- 同一账号多主体时，各主体独立判断

### 有效期规则
- 认证授权有效期：**一年**
- 到期前10天发送提醒消息
- 到期当天发送到期消息
- 到期后重新认证流程与首次认证一致（文案不同）

### 签署合同拦截规则
- 未认证 → 弹窗拦截 → 完成认证后自动返回继续签署
- 审核中 → 不能继续签署
- 审核通过 → 再次进入合同点击"立即签署"自动进入下一流程
- 关闭弹窗 → 留在当前合同页面

## 设计稿关键交互点

### 固定入口横幅样式（从设计稿提取）
- **位置**：位于页面关键信息区块之间（如基本信息与实名认证之间、订单与邀请码之间、统计卡片与行动中心之间）
- **样式**：白色卡片容器，左侧紫色圆形"签"字图标，中间标题"电子签名服务升级"+ 描述文案，右侧紫色"去升级"按钮
- **红框标注**：设计稿中用红色边框标注了横幅插入位置

### 认证页面交互（从 PRD 文字提取）
- 协议区域可滚动，底部有轻提示
- 验证码输入框 + 获取验证码按钮（倒计时）
- 下一步按钮（条件性可点击）

### 补充设计图交互（2026-11-02）
- 合同签署触发的个人 / 法人认证使用“电子签名认证”弹窗；关闭按钮仅关闭弹窗并保留当前合同页。
- 经办人首次拦截使用“补充授权委托书”弹窗，包含下载模板链接、上传区及提交按钮；设计图标注支持 PDF、JPG、PNG，单文件不超过 20MB。
- 经办人进入人工审核后展示“授权委托书审核中”结果态；审核不通过展示审核结果与“重新上传”按钮。
- 独立认证入口中的个人认证使用步骤页，并在第 03 步展示协议阅读、滑动提示、验证码和提交控件。
